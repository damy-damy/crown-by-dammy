# Crown by Dammy 👑

A beautiful hair business website built with React and Vite.

## About the Project

Crown by Dammy is a hair business website where customers can explore hair products and shop online.

## Technologies Used

- React
- Vite
- Tailwind CSS
- Firebase

## Getting Started

Install the project dependencies:

```bash
npm install
```

Start the development server:

```bash
npm run dev
```
